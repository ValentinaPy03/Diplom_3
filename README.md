## Дипломный проект. Задание 3: UI-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Протестированы такие функциональности: 
* восстановление пароля
* личный кабинет
* проверка основного функционала
* раздел "Лента заказов"


### Структура проекта

- `locators` - пакет, содержащий локаторы для работы с тестами, разделенный по страницам
- `tests` - пакет, содержащий тесты, разделенные по классам
- `pages` - пакет с методами отдельных страниц
- `methods` - API методы для создания и удаления тестового пользователя

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание allure-отчета**

>  `$ pytest --alluredir=allure_results`
> 
>  `$ allure serve allure_results`
